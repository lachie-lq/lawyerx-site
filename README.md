# 肖通律师个人网站｜图文自助发布版

正式域名：`https://lawyerx.com`

这一版在原静态网站基础上加入了 **Decap CMS 内容后台**。完成一次部署配置后，可以在浏览器中登录后台，自行新增、修改和删除文章，并上传封面图及正文图片，无需手工修改 HTML。

## 已支持的自助功能

- 浏览器后台发布图文文章
- 富文本与 Markdown 两种编辑方式
- 上传文章封面图
- 在正文任意位置插入图片
- 选择文章分类
- 设置首页推荐文章
- 保存草稿，草稿不公开展示
- 自动更新首页文章卡片、文章目录、文章详情页
- 自动生成 `sitemap.xml`、`llms.txt`、RSS 和文章 JSON 索引
- 自动生成 Article 结构化数据、Open Graph 与 canonical 信息

## 后台地址

网站上线后访问：

```text
https://lawyerx.com/admin/
```

## 推荐部署方式：GitHub + Netlify

后台发布依赖 Git 仓库和身份验证，不能只把 `_site` 文件夹拖到普通服务器后直接使用后台。

### 第一步：建立 GitHub 仓库

1. 注册或登录 GitHub。
2. 新建一个私有仓库，例如 `lawyerx-site`。
3. 将本压缩包解压后的全部源文件上传到仓库根目录。
4. 默认分支应为 `main`。

### 第二步：连接 Netlify

1. 登录 Netlify，选择从已有 Git 仓库创建项目。
2. 连接上述 GitHub 仓库。
3. 构建命令填写：`node build.js`
4. 发布目录填写：`_site`
5. 部署完成后，在 Netlify 添加自定义域名 `lawyerx.com`。

项目内的 `netlify.toml` 已写好相同配置，通常可自动识别。

### 第三步：启用文章后台登录

1. 在 Netlify 项目设置中启用 **Identity**。
2. 注册方式设置为 **Invite only**，避免任何人自行注册。
3. 在 Identity 服务中启用 **Git Gateway**。
4. 邀请你自己的邮箱成为后台用户。
5. 从邀请邮件打开激活链接并设置密码；首页已配置自动跳转后台。
6. 访问 `https://lawyerx.com/admin/` 登录。

### 第四步：自行发布图文

进入后台后：

1. 点击“专业文章”；
2. 点击“新建文章”；
3. 填写标题、搜索摘要、列表摘要和分类；
4. 上传封面图；
5. 在正文编辑器中输入文字、插入标题、列表和图片；
6. 不希望立即公开时，打开“保存为草稿”；
7. 点击“发布”。

发布后，系统会向 GitHub 保存内容，Netlify 自动重新构建网站。通常稍等片刻即可在首页和文章栏目看到新文章。

## 图片建议

- 封面图建议比例：`16:9` 或 `4:3`
- 建议宽度：1200 至 2000 像素
- 单张图片建议控制在 2MB 以内
- 图片上传时填写准确的图片说明，便于搜索引擎和生成式 AI 理解
- 不要上传未经授权的客户资料、未公开证据或含敏感个人信息的图片

## 本地构建与预览

项目不依赖第三方构建包，只需要 Node.js：

```bash
node build.js
python3 -m http.server 8080 -d _site
```

浏览器打开：

```text
http://localhost:8080
```

## 目录说明

```text
content/articles/       文章源文件，后台发布后自动写入这里
static/uploads/         后台上传的图片
static/admin/           内容管理后台
static/assets/          网站样式、脚本和固定图片
templates/              首页、列表页和文章页模板
build.js                自动生成网站的构建程序
_site/                   构建后的公开网站文件
netlify.toml             Netlify部署配置
```

## 重要安全提示

- Identity 必须使用 Invite only。
- Netlify、GitHub和域名账户均应开启双重验证。
- 不要把账户密码、API密钥或客户隐私写入文章。
- `/admin/` 页面已设置不允许搜索引擎收录，但后台安全仍依赖账户权限和密码。
